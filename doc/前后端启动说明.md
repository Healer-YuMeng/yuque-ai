# 前后端启动说明

本文整理在本仓库中**启动后端（FastAPI）**与**启动前端（Vite）**的常用命令与地址。更完整的项目说明见 [README.md](../README.md)，Agent 协作约定见 [AGENTS.md](../AGENTS.md)。

**仓库根目录**（下文中「根目录」均指克隆后的项目根路径，例如 `yuque-rag-demo/`）。

---

## 1. 启动前准备（首次或换机器）

在根目录执行：

```bash
cd /path/to/yuque-rag-demo
source scripts/activate.sh
python -m pip install -r requirements.txt
cp .env.example .env
```

然后编辑根目录下的 `.env`，至少配置语雀与 LLM 相关变量（详见 [.env.example](../.env.example) 与 [README.md](../README.md)）。

前端依赖（首次或 `package.json` 变更后）：

```bash
cd frontend
npm install
cd ..
```

---

## 2. 方式一：一键同时启动后端 + 前端（推荐联调）

在**仓库根目录**：

```bash
make dev
```

等价于：

```bash
./scripts/dev_up.sh
```

效果：

- **后端**：FastAPI + Uvicorn，默认 `http://127.0.0.1:8000`
- **前端**：Vite 开发服务器，脚本中为 `http://127.0.0.1:5173`（若本机 `dev_up.sh` 里 npm 路径与你不一致，见下文「常见问题」）

停止联调占用的端口：

```bash
make down
```

查看 8000 / 5173 是否在监听：

```bash
make status
```

---

## 3. 方式二：两个终端分别启动（便于分别看日志）

### 终端 A：仅后端

在**仓库根目录**：

```bash
cd /path/to/yuque-rag-demo
make run
```

说明：`make run` 会使用 `./yuqueai/bin/python -m uvicorn ...`，**不要求**你先执行 `source scripts/activate.sh`（虚拟环境目录默认为 `./yuqueai`）。

若不用 Make，也可手动：

```bash
cd /path/to/yuque-rag-demo
source scripts/activate.sh
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 终端 B：仅前端（开发态）

在**仓库根目录**下进入 `frontend`：

```bash
cd /path/to/yuque-rag-demo/frontend
npm run dev
```

默认开发地址一般为 **`http://localhost:5173/`**（以终端输出为准）。  
此模式下，Vite 会把 `/chat`、`/mcp`、`/docs` 等请求**代理**到本机 `8000` 端口的后端，因此需**先保证后端已启动**。

---

## 4. 方式三：只开一个服务（生产演示 / 单端口）

先构建前端静态资源，再由 FastAPI 托管（只占用 **8000**）：

```bash
cd /path/to/yuque-rag-demo
make build-ui
make run
```

浏览器打开：**`http://127.0.0.1:8000/`**（不建议用 `http://0.0.0.0:8000` 作为浏览器地址）。

说明：存在 `frontend/dist` 时，根路径会走 React 构建产物；否则回退到 `web/` 静态页（见 [web/README_LEGACY.md](../web/README_LEGACY.md)）。

## 5. 命令速查表

| 场景 | 命令 | 工作目录 |
|------|------|----------|
| 联调：后端 + 前端 | `make dev` 或 `./scripts/dev_up.sh` | 根目录 |
| 仅后端 | `make run` | 根目录 |
| 仅后端（手动） | `source scripts/activate.sh` 后 `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000` | 根目录 |
| 仅前端开发 | `npm run dev` | `frontend/` |
| 构建前端产物 | `make build-ui` 或 `./scripts/build_frontend.sh` | 根目录 |
| 停止 8000/5173 相关进程 | `make down` | 根目录 |
| 查看端口状态 | `make status` | 根目录 |

## 6. 启动后访问地址

| 服务 | 典型地址 | 说明 |
|------|----------|------|
| FastAPI | `http://127.0.0.1:8000/` | 单端口模式下的 Web 与 API 同源 |
| FastAPI 文档 | `http://127.0.0.1:8000/docs` | Swagger |
| 健康检查 | `http://127.0.0.1:8000/health` | |
| Vite（联调） | 以终端为准，多为 `http://localhost:5173/` | 与 8000 同时使用时用于热更新前端 |

## 7. 常见问题

**1）提示 `command not found: uvicorn`**  
未激活虚拟环境或未用 `make run`。请使用 `make run`，或先 `source scripts/activate.sh` 再执行 `uvicorn`，或使用 `./yuqueai/bin/python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`。

**2）`./scripts/dev_up.sh` 或 `build_frontend.sh` 里 npm 找不到**  
脚本中可能写死了 ` /opt/homebrew/bin/npm`。若你本机 Node 不在该路径，请改用「方式二」在 `frontend` 目录直接用 `npm install` / `npm run dev`，或自行修改脚本中的 npm 路径。

**3）`localhost` 与 `127.0.0.1` 打开页面不一样**  
浏览器按**源**隔离本地存储。开发时尽量固定用一种地址访问前端，否则 `localStorage` 中的会话缓存可能互不共享。
