## 项目一句话说明

该项目是一个基于语雀知识库的企业级 RAG 问答系统 MVP，主链路为：

- `FastAPI` 提供问答、目录、索引与健康检查接口
- `React + Vite` 提供聊天式前端界面
- `YuqueLoader` 负责访问语雀 OpenAPI
- `VectorStore` 负责本地向量索引持久化与相似度检索
- `RAGPipeline` 串联检索、可选插图增强和大模型生成
- `YuqueMCPClient` 在向量召回弱或 OpenAPI 不适用时提供 MCP 回退检索
