# 语雀智能销售助手 V1.5 命令清单

本文用于本地快速验证 V1.5「多媒体优先（/chat/v2）」链路。

## 1. 环境准备

```bash
cd /Users/zhaojinyang/AiProjects/yuque-rag-demo
source scripts/activate.sh
python -m pip install -r requirements.txt
```

前端依赖（首次或依赖变更后执行）：

```bash
cd /Users/zhaojinyang/AiProjects/yuque-rag-demo/frontend
npm install
```

## 2. 打开 V1.5 开关

在仓库根目录 `.env` 中确认以下配置：

```env
CHAT_V15_ENABLED=true
CHAT_V15_MAX_IMAGES=3
CHAT_V15_MAX_VIDEOS=1
CHAT_V15_MAX_DOCS=6
CHAT_V15_LEAD_NUDGE_ROUNDS=5
CHAT_V15_LEAD_NUDGE_STAY_S=120
```

前端若要走 `/chat/v2/stream`，请在前端环境变量中开启：

```env
VITE_CHAT_V2_ENABLED=true
```

## 5. V1.5 非流式接口验证

```bash
curl -sS -X POST "http://127.0.0.1:8000/chat/v2" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "请给我一个平台功能介绍，并尽量附上相关图片或视频",
    "chat_mode": "visitor_sales",
    "token_profile": "primary",
    "session_id": "v15-demo-001"
  }'
```

检查要点：
- 返回 `answer_style=short_sales`
- `media.images` 数量不超过 3
- `media.videos` 数量不超过 1
- `lead_nudge_triggered` 字段存在

## 6. V1.5 流式接口验证（SSE）

```bash
curl -N -X POST "http://127.0.0.1:8000/chat/v2/stream" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "有没有演示视频？",
    "chat_mode": "visitor_sales",
    "token_profile": "primary",
    "session_id": "v15-demo-002"
  }'
```

检查要点：
- 包含 `event: stage`
- 包含 `event: token`
- 最终有 `event: done`
