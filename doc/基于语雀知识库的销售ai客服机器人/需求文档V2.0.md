## 一、版本定位与演进关系

### 1.1 产品定位

面向学校/机构/家长访客的 **AI 销售顾问**：基于语雀知识库中的产品文档，通过自然对话完成 **产品介绍、目录内引导、案例讲解、留资与试用申请**；回答须贴合目录结构，不暴露「语雀/知识库/RAG」等技术用语。

### 1.2 与 V1.5 的关系

| 维度 | V1.5 | V2.0 |
|------|------|------|
| 主链路 | 多媒体优先编排（V2 接口） | **V4 目录状态机 + 语雀 MCP 直连** |
| 检索 | Skill + MCP，弱化 RAG | **销售场景不走向量 RAG** |
| Skill | 单路由或关闭 | **用户提问后动态多选 Skill，一次合成回答** |
| 对话结构 | 偏单次问答 | **四级目录状态机 + 会话画像持久化** |
| 可观测性 | 开发者面板偏 RAG 字段 | **本轮运行追踪：MCP / Skill / 文档** |

V2.0 在 V1.5 能力之上 **增量叠加**，不删除 V1/V2/V3 旁路；生产环境以 **V4 + visitor_sales** 为主入口。

### 1.3 交付形态说明

- **对客户**：仅聊天主界面（无开发者面板、不展示来源链接与内部 trace）。
- **对内部**：保留可折叠开发者面板，用于验收「本轮调用了哪些 MCP、Skill、文档」；上线前通过配置关闭面板。

## 二、用户与场景

### 2.1 目标用户

| 角色 | 典型诉求 |
|------|----------|
| 教师 | 平台功能、备课上课、课程落地、试用 |
| 家长 | 孩子学什么、课程选择、升学衔接 |
| 校方/机构负责人 | 方案、部署、成效、采购对接 |

### 2.2 核心场景

1. 首次访问：平台介绍 + 按目录引导选择模块（不跨一级模块乱推）。
2. 深入某一模块（如「案例与社区 → 跨学科项目式学习」）：基于语雀正文讲解，可配图，可关联同级文档补充细节。
3. 留资/试用：在合适时机收集姓名、单位、联系方式、感兴趣的内容；已留资不再重复索要。
4. 身份与记忆：称呼、身份（学生/老师/家长等）一次识别后持久化，更正后以最后一次自述为准。

## 三、功能需求

### 模块 1：语雀知识接入（非 RAG）

**原则**：销售主链 **不使用向量检索（FAISS）**；知识来自语雀 **目录（TOC）+ MCP 按需拉正文**。

| 编号 | 需求 | 验收要点 |
|------|------|----------|
| K-01 | 服务启动或定时刷新时预热语雀 **目录结构（TOC）** | V4 状态机可立即匹配节点；刷新间隔可配置 |
| K-02 | 用户进入具体模块后，通过 MCP **搜索 + 读取多篇文档正文** | 主文档 + 同目录关联文档；不全站 list_docs |
| K-03 | 图片仅从 **当前主文档** 抽取，禁止跨文档混图 | 试用账号等纯留资问题不出无关配图 |
| K-04 | 正文用于生成，不向访客展示原始图片 URL | 前端同源代理展示 |

**MCP 工具范围（销售主链）**

| 工具 | 用途 | 是否打开站预拉 |
|------|------|----------------|
| yuque_search | 按目录路径+标题搜索文档 | 否 |
| yuque_get_doc | 读取文档正文 | 否 |
| yuque_get_toc | 读目录（与 HTTP TOC 等价） | 由 HTTP 预热承担，一般不重复调 MCP |
| yuque_list_docs / list_books | 管理/兜底 | 非主链必须 |

---

### 模块 2：动态多 Skill 编排

**原则**：Skill 是 **输出格式与任务约束**（generation_instruction），不是每个 Skill 各跑一遍完整问答；**汇总后只调用一次大模型（DeepSeek）**。

| 编号 | 需求 | 验收要点 |
|------|------|----------|
| S-01 | 用户提问后，系统 **动态选择 0~N 个 Skill**（N 建议 ≤3） | 非写死固定组合 |
| S-02 | 销售白名单内 Skill 可被选中 | 见下表 |
| S-03 | 非销售 Skill 不得在销售链触发 | 过期检测、笔记润色、碎片捕获等 |
| S-04 | 目录引导层（浅层对话）默认 **0 个 Skill** | 仅模板/轻量引导文案 |
| S-05 | 多个 Skill 的指令 **合并进同一条生成 prompt** | 延迟与成本不随 Skill 数量线性倍增 |

**销售可用 Skill 池**

| Skill ID | 中文名 | 典型触发 |
|----------|--------|----------|
| smart-summary | 智能摘要 | 总结、概述、要点、简要介绍 |
| smart-search | 智能搜索回答 | 找文档、在哪里、有哪些 |
| knowledge-connect | 知识关联 | 对比、关联、和 XX 有什么关系 |
| reading-digest | 阅读笔记 | 仅当用户明确要笔记/金句/行动项 |

---

### 模块 3：四级目录状态机

| 编号 | 需求 | 验收要点 |
|------|------|----------|
| D-01 | 对话沿语雀 TOC **四级目录** 推进，状态 **不回退**（除非用户重置） | 路径与知识库一致 |
| D-02 | 推荐仅限 **当前目录同级/关联节点**，禁止跨一级模块（如在「案例与社区」推「智能招生」） | 专项用例必过 |
| D-03 | 深度讲解（状态 2/3）**不强制**每轮末尾固定模板句「同模块里还可以看看…」 | 仅用户主动表示想看其他内容时才自然推荐 |
| D-04 | 同一话题多次追问时 **逐层加深**，禁止大段重复粘贴相同文案 | 结合关联文档补充新信息 |

**推荐边界示例**

- 当前节点：`案例与社区 > 优秀案例库 > 跨学科项目式学习`
- 允许推荐：同级「人工智能通识课程」等案例
- 禁止推荐：智能招生、使用指南、平台介绍（跨一级模块）

---

### 模块 4：会话画像与留资

| 编号 | 需求 | 验收要点 |
|------|------|----------|
| P-01 | 自动记忆：身份、姓名、单位、联系方式、感兴趣内容 | SQLite 持久化，跨轮有效 |
| P-02 | 身份以 **最后一次用户自述** 为准；「其实我是老师」可覆盖先前「学生」 | 身份切换用例 |
| P-03 | 学科/年级类问题 **整场最多主动问 1 次**；已问过不再追问 | |
| P-04 | 已提交联系方式后 **不再二次索要**；留资/试用引导 **整场最多 1 次** | |
| P-05 | 正常内容讲解 **中间不插入** 留资/试用话术 | 仅在收尾或满足轮次/停留策略时 |
| P-06 | 留资缺失项文案包含：**姓名、单位、联系方式、感兴趣的内容** | 称呼使用完整 display（如「赵老师」） |

---

### 模块 5：回答内容与多媒体

| 编号 | 需求 | 验收要点 |
|------|------|----------|
| C-01 | 仅基于给定语雀上下文回答，禁止编造目录外模块 | |
| C-02 | 有配图时正文精炼（约 60~120 字），禁止说「没有图片」 | |
| C-03 | 图片/视频数量上限：图片 ≤3，视频 ≤1（与 V1.5 一致） | |
| C-04 | 禁止出现语雀、知识库、目录结构等对内用语 | |
| C-05 | 流式输出体验稳定，不因前端逐字刷新导致浏览器内存暴涨 | 见开发文档 |

---

### 模块 6：内部运行追踪（开发者面板，非客户功能）

| 编号 | 需求 | 验收要点 |
|------|------|----------|
| T-01 | 每轮对话结束后，内部面板展示 **本轮 MCP 调用列表**（工具名、query/doc_id、结果摘要） | |
| T-02 | 展示 **本轮选中的 Skill**（skill_id + 触发原因） | |
| T-03 | 展示 **本轮使用的文档**（标题、doc_id、主文档/关联文档角色） | |
| T-04 | 通过环境变量可 **关闭开发者面板** 与 trace 下发，便于客户版构建 | `VITE_SHOW_DEV_PANEL` / `EXPOSE_TURN_TRACE` |

## 四、非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 常规问答首字 < 3s（视 MCP 与模型而定）；多媒体场景建议 < 8s |
| 稳定性 | MCP 失败可降级短文案；单轮失败不拖垮整站 |
| 安全 | 生产关闭 turn_trace；密钥仅环境变量 |
| 兼容 | V1/V2/V3 旁路可回归；默认前端优先 V4 |
| 可维护 | 开闭原则：销售增强不破坏旧 `chat_mode=rag` 与 skill 单路由 |

## 五、验收用例（专项）

| 序号 | 场景 | 预期 |
|------|------|------|
| 1 | 身份切换：先学生后老师 | 最终锁定老师，话术用「X老师」，不反复确认身份 |
| 2 | 已留资 | 全程不再索要电话/微信/试用弹窗骚扰 |
| 3 | 案例库-跨学科项目式学习 | 不推荐智能招生；可提同级通识课案例 |
| 4 | 案例讲解 | 有图则展示；无跨文档无关图 |
| 5 | 同主题连问 3 次 | 内容递进，无大段重复 |
| 6 | 引导话术 | 无固定「同模块里还可以看看 A、B。您想继续聊哪一块？」每轮必现 |
| 7 | 留资 | 整场最多 1 次；讲解中不插入 |
| 8 | 开发者面板 | 可见 MCP、Skill、文档三类信息；客户构建面板隐藏 |

## 六、范围边界

### 本期做

- V4 主链：动态 Skill 计划 + MCP 取数 + 单次 DeepSeek 合成
- turn_trace 与开发者面板改造
- 会话画像、目录状态机、留资策略（在 V1.5/V4 已有基础上补强规则）

### 本期不做

- 向量 RAG 作为销售主检索
- CRM、线索分配、人工坐席后台
- 每个 Skill 独立跑完整流水线再拼接
- 客户侧展示参考来源 URL（保持 visitor_sales 掩码）

---

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| MCP 延迟或失败 | 超时降级；限制单次 get_doc 数量 |
| 多 Skill 指令过长 | 限制 N≤3；精简 instruction |
| 目录与语雀不同步 | TOC 定时刷新；可手动刷新侧栏目录 |
| 内部 trace 泄露 | 生产 `EXPOSE_TURN_TRACE=false` |
