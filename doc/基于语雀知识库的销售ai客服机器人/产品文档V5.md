## 1. 架构定位

### 1.1 V5 在现有链路中的位置

| 链路 | HTTP | 编排器 | chat_mode | 本规格 |
|------|------|--------|-----------|--------|
| **V5 朋友（实施对象）** | `POST /chat/v5/stream` | `FriendDialogOrchestratorV5` | `friend_v5` | **是** |
| V4 销售 | `POST /chat/v4/stream` | `SalesDialogOrchestratorV4` | `visitor_sales` | 否 |
| V3 画像推荐 | `POST /chat/v3/stream` | `SalesDialogOrchestratorV3` | `visitor_sales` | 否 |
| V2 多媒体 | `POST /chat/v2/stream` | `MediaAnswerOrchestrator` | `visitor_sales` | 否 |
| V1 RAG | `POST /chat/stream` | `RAGPipeline` | `rag` | 否 |

### 1.2 设计原则

- **独立实现**：V5 不自带 V4 历史包袱，不在 V4 代码上打补丁
- **最小改动**：复用 ProfileExtractor（画像采集）、MCP Client（语雀检索）、Generator 基类（LLM 调用）；新增部分仅为人设模板 + 编排器 + 路由
- **联网搜索优先**：每轮 LLM 请求携带 `enable_search=true`，让模型自主查网络信息
- **简化链路**：无目录状态机、无 Skill 规划、无留资引导

### 2.2 人设关键约束

```text
【角色定位】
- 你是「小为」，有为人工智能教育平台的朋友向导
- 面向对 AI 科创教育感兴趣的访客，提供产品介绍、方向梳理和建议
- 风格：自然、真诚、放松，像朋友聊天，不是销售、不是客服、不是问卷机器人

【产品范围】
平台主营 4 类核心产品：
1. 人工智能通识课程：适配中小学 AI 科普教学
2. 跨学科项目式学习：PBL 项目化科创课程
3. 智能招生：AI 获客与转化工具
4. 学校 AI 场景定制：定制实验室、校本课程和落地方案

【联网搜索规则】
- 每轮回答前，基于「搜索结果」给出内容丰富的产品彩页式介绍
- 搜索到的图片、视频可以自然引用
- 搜索结果不包含的内容，坦诚说明不编造

【信息采集规则】
- 只收集 2 项：称呼、单位
- 每轮最多只问 1 项
- 信息采集自然穿插，不表单式追问
- 用户拒绝不纠缠
- **不主动索要联系方式**

【推荐标签规则】
- 每轮返回 3 个推荐标签，标签必须来自当前语雀目录标题
- LLM 输出的 [TAGS] ... [END_TAGS] 只作为匹配线索，不能直接展示给用户
- 标签文本必须与语雀目录节点标题一致，禁止随机生成不存在的方向
- 示例："乐高人工智能课程介绍"
- 用户每次刷新 V5 页面时，前端必须重新拉取语雀目录，并进入一个新的 `sess_v5_` 对话

【表达风格】
- 首段承接用户上一句，自然回应
- 中段给出判断或建议 + 2-4 个要点（- **关键词**：说明）
- 末段自然互动提问
- 禁用词汇："顾问"、"销售"、"留资"、"线索"、"试用账号"
```

## 3. 画像采集模块

### 3.1 复用现有组件

| 模块 | 文件 | 用途 |
|------|------|------|
| ProfileExtractor | `app/conversation/profile_extractor.py` | 规则 + LLM 提取称呼/单位 |

### 3.2 V5 画像采集调整

V4 采集 4 项字段（称呼/单位/联系方式/感兴趣产品），V5 精简为 2 项：

- `ProfileExtractor.extract_update()` 本身提取 4 项，V5 编排器中只取前 2 项
- `interests`（兴趣关键词）仍然记录，但仅作画像参考，不用于留资
- 不加载 `V4LeadOutreach`（留资引导模块）
- 不加载 `LeadNudgePolicy`（留资触达策略）

### 3.3 画像字段在 Prompt 中的注入

```text

- 称呼：赵老师
- 单位：育才中学（内部参考，勿写出）
已询问过的字段（禁止再次追问）：称呼

信息采集提醒：
- 还没收集的字段：单位
- 可以自然穿插询问，但每轮最多问 1 项
```

## 4. 流式编排时序

### 4.1 主流程：FriendDialogOrchestratorV5.answer_stream()

```
POST /chat/v5/stream
  { question, session_id, scene, model, history }
        │
        ▼
FriendDialogOrchestratorV5.answer_stream()
        │
        ├─ 1. 加载/更新会话画像
        │     ProfileExtractor.extract_update(question, history, profile)
        │     → 提取 display_name, org_name
        │     → profile_repo.upsert_profile()
        │
        ├─ 2. 构建 V5 Prompt
        │     _build_v5_prompt(
        │       scene=scene,
        │       question=question,
        │       profile=profile,
        │       history=history,
        │     )
        │     → 注入人设模板 + 画像 + 场景 + 对话历史
        │     → 末尾附加 [TAGS] 格式指令（仅作为目录匹配线索）
        │
        ├─ 3. 并行执行
        │     ├─ Generator.stream_generate(enable_search=True)
        │     │   → 向 LLM 发送完整 prompt
        │     │   → extra_body={"enable_search": True}
        │     │   → 流式接收 answer_chunks
        │     │
        │     └─ (可选) YuqueMCPClient.search(question)
        │         → 仅当推荐标签匹配语雀文档时触发
        │         → 返回匹配文档的 URL 列表
        │
        ├─ 4. 解析回答文本
        │     → 剥离 [TAGS] ... [END_TAGS] 块
        │     → 用标签块/问题/场景匹配语雀目录
        │     → tags = 语雀目录中的 3 个节点标题
        │     → answer = 剩余文本（去掉标签块）
        │
        └─ 5. SSE done 事件组装
              → ChatV5Response {
                  answer, tags, sources,
                  profile_fields: { display_name, org_name }
                }
```

### 4.2 与 V4 编排器的关键差异

| 步骤 | V4 | V5 |
|------|-----|-----|
| 画像加载 | ProfileExtractor + V4LeadOutreach | ProfileExtractor（仅取 2 项） |
| 目录状态 | CatalogStateMachine.apply_user_turn() | **无** |
| 文档检索 | _retrieve_for_nodes() → FAISS/MCP 全文 | **无全文检索** |
| Skill 规划 | plan_sales_skills() | **无** |
| 留资引导 | V4LeadOutreach.evaluate_end_of_turn() | **无** |
| Prompt 构建 | _build_v4_prompt() | _build_v5_prompt()（更简洁） |
| 生成器 | Generator(enable_search=False) | Generator(enable_search=True) |
| 标签生成 | 无（由 guide_candidates 决定） | 从语雀目录节点中匹配 3 个标签；LLM 标签块只作线索 |

## 6. Generator + Retriever 设计

### 6.1 Generator 新增 V5 专用方法

在 `app/rag/generator.py` 中新增：

```python
class Generator(ABC):
    # ...

    async def stream_generate_v5(
        self,
        *,
        prompt: str,
        system: str,
    ) -> AsyncIterator[str]:
        """V5 专用流式生成，携带 enable_search=True"""
        logger.info("V5 stream_generate model=%s", self._model)
        stream = await self._client.chat.completions.create(
            model=self._model,
            messages=[
                {"role": "system", "content": system},
                {"role": "user", "content": prompt},
            ],
            stream=True,
            extra_body={"enable_search": True},
            temperature=0.2,
        )
        async for chunk in stream:
            delta = (chunk.choices[0].delta.content or "") if chunk.choices else ""
            if delta:
                yield delta
```

### 6.2 Retriever 不参与 V5 主链路

V5 的信息源是联网搜索，不走向量检索。但在标签匹配场景下，需要语雀文档 URL：

```python
# 在 FriendDialogOrchestratorV5 中新增方法
async def _lookup_yuque_urls(self, question: str) -> list[dict]:
    """用标签内容搜索语雀知识库，返回匹配文档的 URL 列表"""
    if not self._mcp_client or not self._mcp_client.enabled:
        return []
    try:
        result = await self._mcp_client.call_raw("yuque_search", {
            "query": question,
            "limit": 3,
        })
        # 解析 result 为 [{ title, url }]
        return self._parse_search_result(result)
    except Exception:
        return []
```
