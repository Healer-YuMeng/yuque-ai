# 服务启动命令速查

本文只保留你最常用的启动命令，方便直接复制执行。

## 一键启动（推荐）

在项目根目录执行：

```bash
cd /Users/zhaojinyang/AiProjects/yuque-rag-demo
make dev
```

作用：

- 同时启动后端（`8000`）和前端开发服务（`5173`）
- 适合日常联调

## 分开启动（两个终端）

### 终端 1：后端

```bash
cd /Users/zhaojinyang/AiProjects/yuque-rag-demo
make run
```

### 终端 2：前端

```bash
cd /Users/zhaojinyang/AiProjects/yuque-rag-demo/frontend
npm run dev
```

## 停止服务

在项目根目录执行：

```bash
cd /Users/zhaojinyang/AiProjects/yuque-rag-demo
make down
```

## 常用访问地址

- 开发者页面（前端热更新）：`http://127.0.0.1:5173/`
- 开发者页面（后端托管）：`http://127.0.0.1:8000/`
- 访客页面：`http://127.0.0.1:8000/visitor`
- 快捷入口页：`http://127.0.0.1:8000/dev-links`

## 你最关心的一句话

- 改前端：先看 `5173`
- 改后端：`5173` 和 `8000` 都会走同一个后端逻辑
